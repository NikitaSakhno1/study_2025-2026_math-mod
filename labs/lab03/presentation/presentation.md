# Цель работы

Построить математическую модель боевых действий и провести анализ.

# Задание

Мой вариант определяется по формуле:

```python
a = (1132230298 % 70) + 1
print(a)
```

Получаем вариант **39**.

В начальный момент времени:

- $x(0) = 21050$ — численность армии страны $X$.
- $y(0) = 8900$ — численность армии страны $Y$.

Требуется построить графики изменения численности войск для двух случаев:

1. модель боевых действий между регулярными войсками;
2. модель боевых действий с участием регулярных войск и партизанских отрядов.

# Математическая модель

## 1. Модель боевых действий между регулярными войсками

$$
\frac{dx}{dt} = -0.32x(t) - 0.74y(t) + 2|\sin(t)|
$$

$$
\frac{dy}{dt} = -0.44x(t) - 0.52y(t) + 2|\cos(t)|
$$

Начальные условия:

$$
x(0)=21050, \qquad y(0)=8900
$$

## 2. Модель боевых действий с участием регулярных войск и партизанских отрядов

$$
\frac{dx}{dt} = -0.39x(t) - 0.84y(t) + |\sin(2t)|
$$

$$
\frac{dy}{dt} = -0.42x(t)y(t) - 0.49y(t) + |\cos(2t)|
$$

Начальные условия:

$$
x(0)=21050, \qquad y(0)=8900
$$

# Реализация в Julia

## Код для первой модели

```julia
using DifferentialEquations
using Plots

u0 = [21050.0, 8900.0]
tspan = (0.0, 20.0)

function f1(du, u, p, t)
    du[1] = -0.32*u[1] - 0.74*u[2] + 2*abs(sin(t))
    du[2] = -0.44*u[1] - 0.52*u[2] + 2*abs(cos(t))
end

prob = ODEProblem(f1, u0, tspan)
sol = solve(prob)

plot(sol, label=["x(t)" "y(t)"])
```

## Код для второй модели

```julia
using DifferentialEquations
using Plots

u0 = [21050.0, 8900.0]
tspan = (0.0, 20.0)

function f2(du, u, p, t)
    du[1] = -0.39*u[1] - 0.84*u[2] + abs(sin(2*t))
    du[2] = -0.42*u[1]*u[2] - 0.49*u[2] + abs(cos(2*t))
end

prob = ODEProblem(f2, u0, tspan)
sol = solve(prob)

plot(sol, label=["x(t)" "y(t)"])
```
