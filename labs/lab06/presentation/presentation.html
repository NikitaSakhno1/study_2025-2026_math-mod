Цель и исходные данные

Цель

Исследовать математическую модель эпидемии и численно решить систему дифференциальных уравнений в Julia.

Исходные данные

  • N = 5424
  • I(0) = 145
  • R(0) = 9
  • S(0) = 5270
  • I* = 300
  • α = 0,01; β = 0,02
  • t ∈ [0; 200]

Математическая модель

Переменные: S(t) — восприимчивые; I(t) — инфицированные; R(t) — имеющие иммунитет.

При I(t) > I*
dS/dt = −αSI
dI/dt = αSI − βI
dR/dt = βI
При I(t) ≤ I*
dS/dt = 0
dI/dt = −βI
dR/dt = βI

Два рассматриваемых случая

Случай 1: I(0) ≤ I*

I(0) = 145 ≤ 300

S(0) = 5270, I(0) = 145, R(0) = 9

Инфицированные изолированы и не заражают восприимчивых.

Случай 2: I(0) > I*

I(0) = 400 > 300

S(0) = 5015, I(0) = 400, R(0) = 9

Происходит распространение инфекции.

Julia: DifferentialEquations — решение системы; Plots — построение графиков.

Результаты и вывод

При I(0) = 145 заражение восприимчивых не происходит. При I(0) = 400 начинается распространение инфекции и численность S(t) уменьшается.
